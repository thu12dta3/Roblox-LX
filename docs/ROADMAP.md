# Roadmap

- [x] M0 repository baseline and feasibility research (documentary; no client test).
- [x] M1 initial proprietary license, documentation, and project foundation.
- [x] M2 first CLI diagnostics and unit coverage.
- [ ] M3 wait for Roblox to release a native Linux desktop client or publish an official interface for one (external blocker).
- [ ] M4 integrate the official native client/interface only after it exists and its use is authorized.
- [ ] M5 validate native rendering, audio, input, and network behavior on Linux.
- [ ] M6 build packaging and game compatibility coverage for that official native path.

No milestone implies Roblox is playable. Current project launch state is BLOCKED. Wine, Darling, virtual machines, and emulators are excluded because they do not meet the native-only requirement.
